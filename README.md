## Short Description 
This game was made for Western's 2212 Compsci course for the 2025 winter term, Made by Tam, Wyatt, Connor, Emma, and Yousef. This game is a virtual pet game where you care for a pet, ensuring its vital stats don't fall too low. There are also items you get to feed and make your pet happy that you can earn through an educational game. The game saves progress so you can take care of multiple pets; for parents, there is a setting that allows you to manage your children's playtime. Enjoy picking, naming and taking care of your pet!

## Required libraries and third party tools
The required libraries for this game are: JSWING, Java.util, java.awt, java.time, java.URL

## Step by step guide for building our project
Install java and confirm you have version 11 or higher by running java -version in the terminal
Click run in your IDE and chose main as the class you'd like to run


## User guide
The main menu will greet you once you run the game. You can make a new pet, load a new pet, view the tutorial, and set parental controls. I'd suggest reading the tutorial before making a pet, as the tutorial explains everything about the game. But the gist of the game is that you have a pet that you have to take care of with commands and items, making sure their vitals stats don't go too low. 

## Parental controls'
You will set a password to access the parental controls. You will have the option to see play time and average play time per session. You will be able to reset that time. You will be able to set restrictions on the times they are allowed to play. You will also be able to revive a dead pet by giving its name.
